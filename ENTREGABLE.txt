Descripción:
- Aplicación de escritorio para gestionar grupos de investigación, investigadores y productos.
- Interfaz gráfica: CustomTkinter (ventana 1200x700, pestañas Grupos/Investigadores/Productos/Estadísticas).
- Persistencia: intenta PostgreSQL; si falla, usa JSON automáticamente (sin cuadro de advertencia al iniciar).
- Datos de ejemplo cargados desde python/datos/datos.json al iniciar.

Funcionalidades actuales:
- Menú: Archivo (Cargar/Guardar/Salir), Datos (Descargar SCIENTI / Cargar CSV), Ayuda (Acerca de).
- Pestañas con botones Crear/Editar/Desactivar/Activar/Eliminar/Actualizar.
- Productos: filtro por año (Todos / Últimos 2 / Últimos 5 / Personalizado).
- Estadísticas: 3 tarjetas con totales y 3 gráficas (matplotlib) embebidas.
- Formularios para crear/editar entidades.
- Scraping SCIENTI con fallback a CSV.

Ejecución:
- VS Code: F5 con configuración "PEA-i GUI" (launch.json apunta a python/gui/app.py con cwd python).
- Terminal: cd python && python gui/app.py

Dependencias: customtkinter, matplotlib, pandas, requests, beautifulsoup4, psycopg2-binary, python-dotenv, pdfplumber.

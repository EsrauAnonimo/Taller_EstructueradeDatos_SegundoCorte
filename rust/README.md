# PEA-i (Versión Rust)

El proyecto Rust se encuentra dentro de la carpeta [`pea_i/`](./pea_i/).

Consulta [`pea_i/README.md`](./pea_i/README.md) para ver la documentación completa y las instrucciones detalladas de uso.

### Inicio Rápido:
```powershell
cd rust/pea_i
cargo run
```
o ejecutando directamente el ejecutable:
```powershell
.\pea_i\target\debug\pea_i.exe
```

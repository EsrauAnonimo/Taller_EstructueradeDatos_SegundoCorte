# PEA-i (Versión Rust)

El proyecto Rust se encuentra dentro de la carpeta [`pea_i/`](./pea_i/).

Consulta [`MANUAL_DE_USUARIO.md`](./MANUAL_DE_USUARIO.md) para ver el manual de usuario rápido y la explicación de estructuras de datos.

### Inicio Rápido:
- **Desde PowerShell:**
  ```powershell
  .\rust\ejecutar.ps1
  ```
- **Desde CMD o doble clic:**
  ```cmd
  .\rust\ejecutar.bat
  ```
- **Con Cargo:**
  ```powershell
  cd rust/pea_i
  cargo run
  ```
- **O ejecutando directamente el binario compilado:**
  ```powershell
  .\rust\pea_i\target\debug\pea_i.exe
  ```
